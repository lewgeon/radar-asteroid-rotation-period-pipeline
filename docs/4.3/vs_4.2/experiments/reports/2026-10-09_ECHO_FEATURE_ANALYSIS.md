## 2026-10-10：历史特征诊断与统计限制

2026-10-10 最终更新：本文的 RMS 公式和统计表是旧宽度定义的诊断记录；当前代码已删除局部主峰 3 dB 宽度，只保留 90% 能量宽度作为距离宽度特征。旧 RMS 数值不能当作当前特征结果。当前变更见 [删除峰值宽度说明](../../changes/NATIVE_RANGE_FEATURES.md)，文末复现代码显式计算历史 RMS。

本文讨论逐脉冲总能量、距离质心和距离展宽为什么可能缺少清晰的周期曲线，以及如何区分散射模型、特征估计、观测计划和显示方式的影响。适用范围为 4.3 当前 Chirp 网格回波与逐脉冲特征路径；不将本组无接收噪声实验推广为真实雷达性能结论。完整推导见 [CHIRP_INVERSION_WALKTHROUGH.md](../../../CHIRP_INVERSION_WALKTHROUGH.md)，反演说明见 [INVERSION_ALGORITHM.md](../../../INVERSION_ALGORITHM.md)。

### 1. 主要结论

“曲线不光滑”“在已知周期上拟合不好”“未知周期搜索失败”“无法区分自转周期与半周期”是不同问题。绘图改善可读性，特征与插值修正改善估计偏差，周期识别还取决于采样时间、搜索模型和目标对称性。

| 特征或环节 | 主要原因 | 本组证据与限制 |
|---|---|---|
| 总能量 | 相干交叉项造成细密姿态起伏；线性插值另外引入功率损失 | E3 插值伪影明显，E1 影响很小；低阶总能量调制本来就可能弱 |
| 距离质心 | 归一化抑制整行共同增益变化，保留受照表面的功率重心变化 | 本组周期较清楚；归一化不能消除空间不均匀的干涉变化 |
| 距离展宽 | 全窗二阶矩对远端微弱尾部功率高度敏感 | E1/E3 的远端主导二阶矩，局部开窗显著改善低阶周期拟合 |
| 显示 | Run 内脉冲挤在不足一个横向像素内，连线形成竖条 | 改散点、Run 聚合点和局部放大有助阅读，不新增信息 |
| 周期搜索 | 自由逐 Run 截距吸收 Run 间的缓慢周期变化 | 离线 Run 均值拟合与当前逐脉冲反演不是同一个模型 |

DeepSeek 对线性插值、全窗展宽和绘图压缩的主要判断有依据，但散斑独立性、有效样本数与精度增益的推断过强。相干起伏在本仿真中是确定性的：固定视线、刚体单轴自转及相同散射状态下，同一姿态的回波会重复。它可以掩盖低阶周期包络，却不意味着失去周期，不能解释成“每圈重新随机抽一次散斑”。

### 2. 特征定义、单位与完整数据流

#### 2.1 定义与单位

设第 $m$ 个脉冲匹配滤波后的复距离像为 $p_{m,l}$，差分时延轴为 $\tau_{m,l}$，功率为 $D_{m,l}=|p_{m,l}|^2$。差分时延相对该脉冲的几何质心接收事件，由 `row_fast_time_offset_s` 构建；重采样后可采用公共轴。三个量为

$$
Q_m=\sum_l D_{m,l}
$$

$$
\bar\tau_m=\frac{\sum_l D_{m,l}\tau_{m,l}}{Q_m},\qquad \sigma_{\tau,m}=\sqrt{\frac{\sum_l D_{m,l}(\tau_{m,l}-\bar\tau_m)^2}{Q_m}}
$$

| GUI 名称 | 字段 | 实际含义 |
|---|---|---|
| 总能量 | `total_power` | 压缩后样点模平方的离散和，未作焦耳标定 |
| 距离质心 | `range_centroid` | `centroid_delay_s`，单位 s，功率的差分时延重心 |
| 距离展宽 | `range_width` | `rms_width_s`，单位 s，差分时延标准差 |

$Q_m$ 随幅度、参考信号能量、采样率和保留范围变化；即使乘采样间隔，也需匹配滤波增益和系统标定才能解释为物理能量。不同带宽、采样率实验的绝对数值不能直接互比。

本文涉及米的量统一采用差分传播路径 $\rho=c\tau$。单站有 $\rho\simeq2x_{\rm LOS}$，所以径向质心、径向展宽和窗口半宽分别为路径量的一半。原分析“2 m 分辨率”“67.6 m 展宽”“±150 m 开窗”在单站径向尺度上分别约为 1 m、33.8 m、±75 m。双站有 $\rho=\mathbf b^{\mathsf T}\mathbf x$、$\mathbf b=\mathbf u_{\rm tx}+\mathbf u_{\rm rx}$，沿 $\mathbf b$ 方向的空间量应除以 $|\mathbf b|$，在 $|\mathbf b|$ 很小时该解释退化。

提取器不直接使用网格和真周期，但 IQ 已间接依赖它们、视线、载频和姿态。`centroid_compensated` 只去掉公共传播项。时延轴整体平移只改变质心、不改变能量和展宽，是对同一组样点成立的不变量；插值或裁剪改变样点后不再满足此前提。

#### 2.2 生产者到消费者

1. `observation/src/planning.py` 建立每 Run 的连续 ADC 时间轴，以首个质心接收事件为栅格锚点，生成行起点、偏移与有效掩码。每脉冲前后采集余量来自同一个 `target.extent_path_m`，脉宽加在后侧。
2. `echo/src/echo.py` 在每 Run 唯一全局 ADC 整数索引上计算相关脉冲贡献并求和，再映射回二维保存行。生成器已经处理物理脉冲叠加，不能误认为逐行独立生成。
3. `echo/src/dataset.py::save_echo` 保存 IQ、掩码、行偏移、Run 编号和散射时刻；`inversion/src/dataset.py::load_echo` 读取。
4. `inversion/src/inversion.py::prepare_chirp_pulse_profiles` 将无效原始样点置零，做匹配滤波，构建差分时延轴，再对齐到公共轴。
5. `chirp_pulse_range_features` 在对齐后距离像上调用 `range_features`，GUI 用 `lines+markers` 显示。CPI 不足时反演也退回这些特征，但搜索仍传入 `groups=run_id`。

E1/E3 的 `signal_echo_overlap` 与 `window_overlap` 均无标记，重复 ADC 计权不是本组首要原因。其他计划必须区分真实有效回波叠加与保存行共享索引，不能用独占样点归属截断真实叠加信号。

<a id="coherent-mechanism"></a>

### 3. 相干起伏与低阶周期包络

#### 3.1 相干项并非随机噪声

设面元 $i$ 的复贡献为 $z_i(t,\tau)$，功率为

$$
\left|\sum_i z_i\right|^2=\sum_i|z_i|^2+2\operatorname{Re}\sum_{i<j}z_i z_j^*
$$

第一项是非相干功率参考，第二项是相干交叉项。自转改变相对路径与相对相位，使干涉对小姿态变化敏感。1 GHz 对应约 0.300 m 波长，70 m 最大半径对应单站约 140 m 最大差分路径，即约 467 个波长。

但跨越很多相位圈不证明统计独立或指数分布。所有面元共同增加同一个相位甚至完全不改变功率，真正影响干涉的是相对相位。固定几何时这些细结构也随姿态重复，只是一个周期内包含很多高阶谐波。单频拟合残差包含确定性细结构、几何漂移、处理偏差以及可能的噪声，不能全部当作独立散斑噪声。

#### 3.2 相位变化尺度不等于去相关时间

定义面元位置 $\mathbf x_i(t)$、角速度矢量 $\boldsymbol\omega$、角速度模长 $\Omega=2\pi/P$、真周期 $P$ 和波长 $\lambda$。相位符号取决于传播约定，变化速率绝对值为

$$
|\dot\phi_i|=\frac{2\pi}{\lambda}\left|\dot{\mathbf b}^{\mathsf T}\mathbf x_i+\mathbf b^{\mathsf T}(\boldsymbol\omega\times\mathbf x_i)\right|
$$

忽略短时视线变化，可得上界

$$
|\dot\phi_i|\le\frac{2\pi}{\lambda}|\mathbf b|\Omega r_{\perp,i}
$$

原文将模长乘积写成等式，遗漏投影和视线变化。取单站 $|\mathbf b|\simeq2$、$r=70\ \mathrm m$，按最大速率累计一整圈相位的局部时间量级为

$$
t_{2\pi}=\frac{\lambda P}{4\pi r}
$$

E1 的 $P=600$ s 给约 0.205 s，E3 的 $P=10800$ s 给约 3.68 s。它不是测得的功率去相关时间；若以 1 rad 为阈值，数值还会小 $2\pi$ 倍。相关性取决于面元间相对速率、散射权重与分辨率，须估计实际相关函数。固定几何下，间隔整数个周期的样本即使相隔很久，也可完全相关。

减慢自转使短 Run 内起伏减小，支持变化受自转驱动；不能仅凭该控制实验排除网格离散、随姿态变化的数值误差或其他移动计划中的插值伪影。

#### 3.3 三个量的物理调制强度并不相同

总能量把不同距离单元相加，距离分布重新排列未必改变积分。球体、近轴对称目标或沿自转轴观察可以几乎没有调制。当前面元振幅是归一化面积乘发射照射与接收可见性权重，非相干功率参考应按振幅平方求和，不能按面积或振幅直接求和。

距离质心的归一化抵消整行共同增益，但保留受照表面功率重心变化，因此本组较清楚。该重心不是几何质心，单站近侧受照表面使路径质心为负并不异常。频率选择性滤波及距离单元内部干涉仍能改变质心；不能保证所有目标都适用。非相干参考的矩也不严格等于相干矩的系综平均，因为平均比值不等于比值的平均。

#### 3.4 原统计解释与网格模型尚需验证

$(\sum_l\mu_l)^2/\sum_l\mu_l^2$ 是平均功率分布的参与率，不自动等于独立距离单元数。总功率方差实际是 $\operatorname{Var}(Q)=\sum_{l,k}\operatorname{Cov}(D_l,D_k)$；只有独立指数功率等额外假设成立时，参与率才可预测相对散度。5 个相关脉冲的中位数/均值低于 1，也不能鉴别“部分发育散斑”。

还需检查空间离散收敛：当前约 1280 个面元被当成质心处的相干散射点，数米级面元与约 0.3 m 波长相比，不能自动代表连续表面相干积分已收敛。若意图模拟光滑椭球，应比较网格加密或面元内相位积分；若意图模拟离散散射中心，应解释中心为何与网格划分绑定。尚无加密实验，不应宣称已证明真实表面散斑或已确认离散模型错误。

### 4. 线性插值的逐脉冲伪影

公共轴对齐分别对实、虚部调用 `np.interp`，这是分段线性插值，见 [NumPy 官方说明](https://numpy.org/doc/stable/reference/generated/numpy.interp.html)。均匀栅格上，令 $d\in[0,1)$ 为分数样点位移，忽略端点截断，有

$$
H(f;d)=(1-d)+d\exp(-j2\pi f/f_s)
$$

$$
|H(f;d)|^2=1-4d(1-d)\sin^2(\pi f/f_s)
$$

本组为 `centered` 复基带，$B=150$ MHz、$f_s=200$ MHz，主要频带约 $[-75,75]$ MHz。在 $f=75$ MHz、$d=0.5$ 时幅度响应约 0.383、功率响应约 0.146，在 $d=0$ 时为 1。它是频率选择性滤波，不是给每行所有频率乘同一个标量；整行损失还依赖频谱和边界。单频边缘响应与总能量比的高相关支持机制，但不能直接定量等同二者。

移动几何下，各行分数位移变化产生处理增益变化。首脉冲是 ADC 锚点，但公共轴起点取所有行起点的中位数，所以首脉冲相对公共轴一般不必严格为零。E3 中近零是具体数据现象。恒定位移仍可能通过频谱变化影响特征，E1 影响很小是本组比较结果，不是静止计划的普遍保证。

三个标量可在原生逐行差分时延轴求矩，避免重采样。CPI 需要列间物理时延一致，可考虑带限分数延迟；FFT 方法须处理零填充和循环移位，sinc 方法须处理有限核、边界与掩码。取消插值不消除有限采样、匹配滤波尾部和记录截断误差。

### 5. 全窗展宽为什么被尾部主导

二阶矩按离质心距离平方加权。矩形 LFM 脉压旁瓣与有限记录的弱尾部延伸很远，因此大部分能量位于目标附近，不保证二阶矩由目标决定。保存行宽度约为脉宽加采集余量，远大于目标时延范围；匹配滤波去掉相关滞后后仍保留输入长度，主瓣左右的保留尾部不对称。

E1 离质心超过 5000 个样点的位置仅含约 0.0024% 总功率，却贡献约 71.4% 二阶矩；E3 对应贡献约 67.1%。200 MHz 下 5000 个样点对应约 7494.8 m 差分路径，平方权重使微弱远端足以主导展宽。这解释全窗宽度为何远大于局部目标宽度、低阶姿态调制被稀释，但不能单独证明所有尾部都是物理旁瓣。应以单散射点、完整相关输出和高精度计算区分真实旁瓣、截断及数值尾部。原脚本左侧越界索引被裁到第零列，相关“±5000 样点电平”不能解释为真实左右对称采样。

局部窗口可从初始质心 $\bar\tau_m^{(0)}$ 出发，以差分路径半宽 $L$ 截取功率，再重新求截取后的质心和展宽：

$$
\widetilde D_{m,l}=D_{m,l}\,\mathbf 1\!\left\{c|\tau_{m,l}-\bar\tau_m^{(0)}|\le L\right\}
$$

$L$ 是特征窗口的新语义，不等于含形体尺度与采集余量的 `target.extent_path_m`。±150 m 路径窗是本组候选，不是通用默认值。窄窗可能截断目标，低能量时初始质心不稳定，阈值跳动可能带来偏差；应扫描窗口、检查目标覆盖率，不能只按最大 $R^2$ 选窗。更大目标、非凸形体、多散射团及噪声还需独立验收。

其他候选包括低旁瓣匹配滤波、能量分位宽度、主目标区域和噪声底估计。低旁瓣处理有主瓣展宽与信噪比代价；确定性旁瓣不是常数噪声底。总能量和质心若也改为局部量，应明确另行命名。

### 6. 观测计划与统计判据

#### 6.1 有效样本数来自协方差

Run 内脉冲数为 $n$、局部残差协方差为 $C_{ij}$，等权均值方差为

$$
\operatorname{Var}(\bar y)=\frac{1}{n^2}\sum_{i,j=1}^n C_{ij}
$$

等方差、近似平稳时，设 lag-$k$ 相关系数为 $r_k$，则

$$
n_{\rm eff}=\frac{n^2}{n+2\sum_{k=1}^{n-1}(n-k)r_k}
$$

高度正相关时接近 1，近似独立时接近 $n$。原文 $1+\Delta t_{\rm run}/t_{\rm dec}$ 是特定相关模型下的启发式，不能由相位变化量级直接推出，也不能据此证明 116→554 或精度提高 2.3 倍。

固定预算下，更多 Run 往往改善相位覆盖并减少短时冗余，但收益取决于相关性、采样窗和系统误差。固定 Run 数时，增加足够分散的新脉冲也可增加总信息；“加长 Run 不改善独立样本总数”错误。延长观测跨度但不增加样本，不必降低每点抖动。Run 内标准差只描述短时变化，不能直接用作 Run 均值标准误或 Run 间散斑误差。

#### 6.2 已知周期拟合不等于未知周期检出

固定候选周期，以共同截距与正弦、余弦拟合 $N$ 个 Run 均值，$R^2$ 描述该低阶模型解释的方差比例，对应

$$
F=\frac{R^2/2}{(1-R^2)/(N-3)}
$$

固定 $N$ 时二者单调等价。“判据是 $F$，不是 $R^2$”过于绝对。经典 $F$ 显著性还需残差等假设；本模型没有自动满足独立同方差条件。未知周期搜索还涉及频率搜索范围、多谐波、相关残差和采样混叠。已知真值上的拟合不提供盲搜检出率或周期置信区间，$\sqrt{F}$ 的变化不能直接称为精度提升。应使用保留相关性的块重采样、重复模拟或协方差模型评估搜索稳定性；相关概念见 [Astropy 周期图与假警率说明](https://docs.astropy.org/en/stable/timeseries/lombscargle.html)。

E1 Run 间隔约 144.23 s，每 300 s 半周期仅约 2.08 个 Run，低阶基频接近规则 Run 采样的 Nyquist 边界，高阶结构易混叠。短 Run 内密集脉冲不自动填补长间隔。E3 增加 Run 是合理候选，但 E2 产物已覆盖，当前无法作去插值后、同处理口径的同会话 A/B；原耗时和“无成本”结论不保留。

#### 6.3 半周期需要对称条件

均匀椭球绕形体对称轴作主轴自转，旋转 $\pi$ 后形状和散射场可等价，从而产生 $P/2$ 重复。当前 `Spin.rotate` 先绕体坐标 z 轴旋转，再将 z 轴映射到配置的天球极轴；配置的赤经、赤纬并不表示相对形体的倾斜自转轴。本组 `ellipsoid.obj` 在 $(x,y,z)\mapsto(-x,-y,z)$ 下，1280 个面元的位置、法向和面积一一对应，且 E1/E3 未启用散射斑，因此固定几何下具有半周期对称的模型依据。变化视线、非对称散射权重或其他不具该对称性的模型可破坏重复；本组 $P/2$ 是强候选，不能无条件定义为整场精确观测周期。

E3 真周期 10800 s 超过 `period_max_s=7200`，5400 s 则在搜索区间内。扩大范围能保留完整周期候选，却不解除严格半周期对称下的 $P$ 与 $P/2$ 歧义；多特征、多谐波和增加样本都不能凭空生成不存在的信息。

#### 6.4 当前搜索模型会吸收 Run 间周期变化

`cpi_duration_s=16`、PRF 10 Hz 需要 160 个脉冲，E1/E3 每 Run 5 个、E2 50 个，不足形成该 CPI。当前 fallback 使用逐脉冲量，再将 Run 编号传给带自由逐组截距的周期搜索。

短 Run 内慢周期近似常数，自由截距能吸收大部分 Run 间调制，只留弱的 Run 内变化。若正弦振幅为 $A$、重复周期为 $P_{\rm obs}$、Run 内跨度为 $\Delta t$，变化上界量级为 $2\pi A\Delta t/P_{\rm obs}$，还依赖所在相位。离线全局 Run 均值拟合与现行反演不能混为一谈。

候选修法是对 fallback 单独设计 Run 聚合、共同截距或受约束基线，同时处理 Run 间增益和几何漂移。删除自由截距可能暴露其他系统偏差，需另行实现与验证。本次只修订文档，并未修复生产算法。

1. 用原生逐行时延轴提取三个标量；另行验证 raw_baseband、有效掩码及边界。CPI 公共栅格重采样单独处理。

#### 2.2 质心接收时刻与 ADC 时刻已知，回波如何生成

两个质心接收时刻只给出两个脉冲的时间参考，不能单独推出每个面元的回波；还需要目标网格、旋转姿态、测站视线、面元散射权重、载频和发射波形。一个 Run 先建立一条连续 ADC 时间轴，各物理采样时刻已知；回波生成器直接在这些时刻评价连续波形模型，计算各面元、各相关脉冲的复数贡献，再求和。

在质心补偿参考下，用最简记号表示：$t_q$ 为 ADC 时刻，$t_{R,m}$ 为第 $m$ 个脉冲的质心参考接收事件，$\Delta R_{i,m,q}$ 为面元相对质心的总传播路径差，$A_{i,m,q}$ 为散射振幅权重，$x_p$ 为发射复基带波形，$c$ 为光速，$f_c$ 为载频。波形内部时间及样点贡献为：

$$
u_{i,m,q}=t_q-t_{R,m}-\frac{\Delta R_{i,m,q}}{c}
$$

$$
z_{i,m,q}=A_{i,m,q}\,x_p(u_{i,m,q})\exp\left(-j\frac{2\pi f_c}{c}\Delta R_{i,m,q}\right),\qquad y_q=\sum_m\sum_i z_{i,m,q}
$$

这是一种便于理解的质心补偿形式；原始基带还包含公共传播路径相位和脉内时间伸缩，运动模型还决定在哪个散射时刻计算姿态。完整符号、原始与补偿公式见 [CHIRP_INVERSION_WALKTHROUGH.md](../../../CHIRP_INVERSION_WALKTHROUGH.md) §1—5。代码并未在每个样点重新解完整三事件几何，而是使用每脉冲几何及选定的脉内运动模型。

“路径更长，回波更晚”与公式中减去路径时延不矛盾：面元回波前沿是 $t_{R,m}+\Delta R/c$，而 $u$ 表示当前样点已经走到这个波形的第几秒，即“当前时刻减波形前沿”。例如参考接收前沿为 100 ns，面元多走约 3 m、晚到约 10 ns；在 115 ns 采样时，$u=115-100-10=5$ ns。不是把到达时刻提前，而是查询延迟波形内部的 5 ns 位置。

因此 $u$ 可以代入发射波形：延迟后的回波在当前时刻的取值，就是原发射波形在相应内部时间的取值，再乘散射幅度和传播相位。若 $u$ 不在脉冲支持区间，贡献为零。当前默认 Chirp 基带以脉冲中点为扫频中心，门控仍以前沿为起点。

论文项目 `D:/Documents/graduate-thesis` 的符号表、第二章回波模型和第三章处理框架用于核对术语。质心路径是公共参考路径，不是把真实扩展目标改成点目标；实际测量的几何质心位置依赖轨迹预测，不应把闭环仿真中已知真值等同于实测无误差。论文没有因此被修改。用户表示后续继续理解回波公式；本轮完成模型解释，没有另行验收实测事件预测误差。

#### 2.3 插值到底为了什么，能不能不对齐

这里区分三种操作：在实际 ADC 时刻计算仿真回波、将各行换到共同差分时延轴、原始基带运动补偿及必要的 CPI 慢时间均匀化。后两者可能使用插值，不能统称为“让信号落在 ADC 上”。完整生产者到消费者关系已列于[数据流](#historical-feature-definition)，线性复数插值的频率响应与替代方法边界见[插值诊断](#linear-alignment)。

每行列坐标加上 `row_fast_time_offset_s` 才是相对该脉冲质心参考事件的时延。教学例子中 ADC 间隔为 5 ns、起点为 85 ns：参考接收事件 100 ns 的行从 85 ns 起，偏移 −15 ns；事件 131.2 ns 的行从 115 ns 起，偏移 −16.2 ns。相同前置样点数不保证同列物理时延相同，但这不表示每组实验都有偏移差异。

本阶段新逐脉冲能量宽度已绕过共同轴重采样，新 CPI 能量宽度仍需对齐；总能量与质心尚未改成原生轴计算，也未完成高质量分数延迟替换。不能据逐脉冲宽度修复承诺 CPI 能量严格守恒。真实回波支持重叠与保存行共享 ADC 索引仍须分开；半开区间只能处理端点归属，本组不构成重叠问题的全面验收。

#### 2.4 原距离展宽是什么，为什么长尾会造成问题

旧量是功率分布在差分时延轴上的标准差；公式、路径／单站径向单位及跨设置不可直接比较总能量的限制统一见[特征定义](#historical-feature-definition)。E1/E3 尾部功率占比和二阶矩贡献统一保留在[尾部诊断](#rms-tails)。脉压输出远离功率重心的延迟样点不等于远处新增目标面元，旧 RMS 也不等于主峰宽度或目标边缘跨度。

用户强调截取的是原信号中很小但非零的长尾，并非在两边补真正的零。加零不会改变功率矩，纳入更多非零尾部会改变结果；改变原始采集窗还可能改变脉压本身。该定义有明确数学意义，但不适合用户希望测量的“主要回波范围”，所以生产距离特征最终删除了它。

给信号模型增加传播距离衰减不能自动修复这一估计器：真实传播衰减描述散射贡献随传播路径变化，不是按脉压输出离主峰的坐标对尾部作衰减。公共幅度因子还会在归一化矩中抵消；非均匀衰减即使改变分布，也不保证去掉远端二阶矩敏感性。本轮没有增加距离衰减因子，也没有用它作为修复方案。

#### 2.6 从 RMS 到 3 dB，再到能量宽度的完整过程

第一步按用户要求把旧 RMS 换成 3 dB 宽度。实现选择最强峰，向左右寻找最近半功率交点，在功率上作线性插值；功率阈值为峰值的 1/2，幅度图上对应峰幅度的 $1/\sqrt{2}$。交点缺失等情况返回 NaN。逐脉冲、CPI、GUI 和 CLI 同步过该阶段定义。

第二步讨论积分式能量宽度是否更稳健。结论是它不依赖一个峰值，也没有距离平方权重，适合主要功率范围；但长尾总功率仍进入分母，所以不保证任意截取长度下不变。曾建议先确定目标门、估计背景或抑制尾部，用户明确决定不采用这些预处理，并要求 3 dB 与能量宽度一起保留。

第三步新增完整脉压的等尾中央 90% 宽度：

$$
C_k=\sum_{j\leq k}P_j,\qquad k_p=\min\{k:C_k\geq pC_{N-1}\},\qquad W_{90}=\tau_{k_{0.95}}-\tau_{k_{0.05}}
$$

分位取首次达到比例的样点，不做端点插值；这是中央等尾区间，不是最短能量区间，离散端点也不保证恰好含 90%。在当前 5 ns 等间隔轴上，端点有样点量化。整个功率缩放不改变宽度；全零、非有限或空功率行不可估计。新增远端非零功率仍可能移动端点。

第四步确定在脉压旧裁剪之前计算。只给完整相关坐标减去滤波滞后即可把主峰参考改为回波前沿，不需要删响应来修正时间原点；删除左侧相关输出可能改变能量比例。新 `full_output=True` 保留完整相关，默认接口仍返回原裁后长度。独立例子中完整输出的 90% 宽度为 4 个样点间隔，裁后仅 2 个，测试刻意区分了这两条路径。“完整”不代表恢复 ADC 采集窗之外未记录的回波。

第五步诊断实际 3 dB 曲线。此前 500 Run、每 Run 5 脉冲的数据中，原生主峰宽度固定 5400 s 单频拟合 $R^2\approx0.0101$，对齐后约 0.0099，去掉共同轴插值并未使它变好。对齐后宽度中位数约 8.228 ns，接近少数采样间隔和点响应尺度；完整能量宽度中位数约 215 ns，拟合约 0.6072；质心约 0.9118。局部峰切换、合并、分裂和谷底过门限会改变该宽度。这些数值用于该已知频率的描述性比较，不是盲搜成功率。

第六步在新单脉冲 Run 数据上标出实际区间。索引 835 的主峰 FWHM 约 7.356 ns，90% 能量宽度为 280 ns；相邻强峰间谷底低于半功率门限，因此局部 FWHM 只包住最强峰的小段。它按已约定的局部 FWHM 规则计算，并非算错了交点，但该测量对象与用户希望覆盖主要回波的需求不一致。不能把“实现通过测试”写成“这个特征适合本任务”。

最后按用户要求删除 3 dB 特征，只保留能量宽度。没有改成首末半功率点的多峰跨度，也没有用任意低门限强行拼成“整个有信号区间”；这种跨度需要另一套定义，长尾非零时也不存在天然的有限可见边界。

#### 2.7 单脉冲 Run 后，总能量尖峰和能量宽度平台为何还在

用户将每 Run 脉冲数降为 1，并增加 Run 数。当前同名产物变为 2000 个脉冲、2000 Run，覆盖了之前的 2500 脉冲、500 Run 数据。新数据所有行偏移完全相同，共同轴对齐前后总功率相对 L2 差为 0。因此该数据仍然出现的总功率尖峰不能归因于共同距离轴插值；“未改插值，所以当前总能量差”这一推断已被纠正。

相干交叉项、姿态相关的散射权重和更高能量基值可以解释尖峰区的绝对振幅变大。按能量宽度上下四分位分组，窄分布样本功率标准差约 3018、宽分布约 1343，绝对起伏约 2.25 倍；相对散度约 27% 与 23%，差别没有绝对幅度那么大。这个分组不是严格的总能量峰谷分组，不能据此声称精确分解了各机制份额。

能量宽度代码没有上限截断或固定距离门。椭球投影范围与受照功率分布不必随姿态形成正弦，主要能量端点也可能形成宽平台；当前数据与这种解释相容，但“平台完全由椭球几何造成”尚无独立控制实验。离散分位、相干分布、弱边缘和几何漂移可能共同影响端点。质心对全体功率作平均、端点不局限于样点位置，因此本组更平滑不意外。

#### 2.8 论文里的旋转多普勒带宽公式与当前特征

用户提出的公式为：

$$
B_{\mathrm{rot}}=\frac{4\pi d}{\lambda P}\cos\theta
$$

这里讨论的是给定几何和理想旋转模型下，速度极值产生的多普勒全跨度，与快时间上的距离宽度是不同维度的量。它不是仅在连续波发射下才有物理意义；相干脉冲列在形成有效 CPI 后也可观察旋转多普勒谱，但要满足 PRF、相干性、分辨率、观测角度和目标边缘可检测等条件。

需要纠正此前“项目已经使用了这个带宽”的过宽说法：项目已有 `rms_bandwidth_hz` / `doppler_bandwidth`，是频谱功率的 RMS 离散度，不是公式中的边缘到边缘全跨度，也没有直接把该公式用于周期计算。谱窗、旁瓣、噪声和散射权重也影响测得的 RMS。两者属于相关的多普勒信息，但不能数值等同。

此前配置 CPI 时长 16 s、PRF 10 Hz，需要 160 个连续且允许相干处理的脉冲；每 Run 5 个、50 个或现在 1 个都不足。本轮增加了可读的不足脉冲提示。增加 Run 时长是使 CPI 可达的一种方法，但还需满足调度、相干分组和运动约束；增加 Run 次数不能替代组内连续脉冲。用户计划后续实验验证，目前没有完成新的长 Run 实验或带宽公式定量对照。

#### 2.10 为什么脉冲压缩反而输出 102 μs

这次发射脉宽为 50 μs，匹配滤波器是完整 Chirp 模板，长度确实接近输入回波保存行。输入 10403 点，模板 10001 点，完整卷积为 $10403+10001-1=20403$ 点；5 ns 间隔下首末跨度分别为 52.01、50、102.01 μs。模板点数来自当前浮点采样间隔与向上取整的实际结果，不应把本次 10001 点写成所有配置的固定模板长度。

脉冲压缩使主要能量集中到窄主峰，不是缩短完整卷积数组。完整滑动相关在部分重叠时仍可能产生弱响应；理想有限 Chirp 自相关的支持范围也可很长。150 MHz 带宽下主峰尺度约为 $1/B\approx6.7$ ns，该量只是尺度，不是精确 FWHM，也不是整个目标的能量宽度。102 μs 是完整滤波输出范围，不能解释成目标主体宽度；对数幅度图显示了此前在线性图上接近零的长尾。

### 4. 尚未得出完整结论或尚未完成的工作

1. **总能量细起伏的因果份额。** 当前已排除共同距离轴插值造成该组尖峰，但相干交叉项、权重变化、网格离散误差和几何漂移各占多少尚未分解；尚无消相干、网格加密、面元内相位积分等控制实验。不能把模型细结构全部叫真实雷达散斑。
2. **能量宽度平台的准确来源。** 非正弦投影与功率分布解释合理，代码无上限裁剪，但还没有几何独立参照证明平台由哪一机制主导。
3. **长尾来源和采集窗敏感性的边界。** 旁瓣、有限记录截断、离散模板和数值误差尚未逐项分解；当前全窗定义仍受长尾累计功率影响，未完成脉宽、采集余量、带宽与分位比例的系统扫描。
4. **总能量、质心和 CPI 的插值改进。** 高质量分数延迟或把其逐脉冲标量移至原生轴均未交付；必要的 CPI 重采样不能承诺无损。
5. **长 Run / 有效 CPI 的实际自转实验。** 用户计划进行，尚未完成。当前现成多普勒特征为 RMS，旋转极值带宽的检测定义、与理论公式的换算及噪声门限尚未建立。
6. **可见范围和其他宽度估计器。** 未实现检测阈值边缘跨度、最短能量窗、自适应门或噪声底处理；用户当前明确选择无门的中央 90% 宽度。
7. **从特征可视周期到可靠盲搜。** 固定已知 5400 s 或 300 s 的拟合不证明未知周期检出率；FAP、置信区间、相关样本数和完整周期/半周期歧义尚未解决。
8. **现有周期搜索基线。** fallback 仍传 `groups=run_id`；此前文档已诊断短 Run 的自由组截距会吸收缓慢调制，该结构没有随宽度替换被修复。每 Run 仅一个样本时更不能把“图有周期”当作搜索可用的保证。
9. **模型和观测契约的进一步验收。** 星历误差、原始基带补偿残差、噪声条件、其他形状、不同网格和重叠采样计划没有被本次特征替换全面验证。
10. **历史数据复现。** E2 与旧 500 Run 产物曾被同名仿真覆盖，某些表只剩冻结记录；重跑当前同名路径不可能重建旧数值。后续应保留输入快照再作 A/B。
