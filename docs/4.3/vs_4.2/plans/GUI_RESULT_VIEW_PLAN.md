3. 上图实际为 CPI 的距离—多普勒功率沿频率求和，不能称为“仅脉冲压缩”；下图是单个 CPI 的距离—多普勒功率，尚未标定横向米坐标。

## 2. 推荐交互：一个入口、一个非模态结果卡片

推荐在顶部操作行保留运行、完整流水线、中止、进度和一个“图像结果 ▾”按钮。所有图像入口集中在同一个锚定弹出卡片，不保留单独“查看回波”“查看特征”“诊断图表”按钮；不再使用独立模态对话框。点击按钮展开，选择图后立即打开浏览器并收起；点击外部或 Esc 收起，没有“确认”和底部大“关闭”按钮。点击统一入口再选图仍是两次点击，不能声称点击次数更少，改进点是统一位置、消除重复、不给用户额外确认流程。

卡片建议分为三组，分组标题只表达处理层次，不增加导航页面。使用现有 GUI 的字体、配色和间距，文本直接可读，不靠图标让用户猜功能。每项一行图名与简短状态，较长说明放悬停提示，不把说明写成一大段挤占点击目标。不要再次设计大面积空白或多层子菜单。

以下是布局草图，不是已经实现的页面。每个图只出现一次；“固定展开”为可选功能，不作为第一阶段必须增加的按钮。

```text
顶部操作行： [运行当前阶段] [完整流水线] [中止]  进度  [图像结果 ▾]
                                                     │
                           ┌─────────────────────────┘
                           │ 图像结果 · 当前实验
                           │ 回波   原始回波       脉冲压缩
                           │ 特征   实际反演特征   逐脉冲检查
                           │ 反演   距离—多普勒   周期搜索
                           └───────────────────────────
```

| 分组 | 唯一入口 | 默认数据与操作 |
| --- | --- | --- |
| 回波 | 原始回波 | 查看原始 IQ 幅度；默认一个完整 Run，不自动计算脉压 |
| 回波 | 脉冲压缩 | 默认最近选中的Run或第1个Run，在完整快时间采样上匹配滤波；图内可切换Run，已有产物直接看 |
| 特征 | 反演实际特征 | 读取上次保存的全部科学特征；标题说明 CPI／逐脉冲、时标与参数快照 |
| 特征 | 逐脉冲检查 | 使用当前补偿／时标；首次需计算的状态明确显示，不冒充保存的反演结果 |
| 反演 | 距离—多普勒 | 默认最近Run与CPI或首个可用CPI，显示完整距离分辨率的选定帧；图内可切换，抽样概览另行切换 |
| 反演 | 周期搜索 | 显示各特征曲线、候选、现有选择规则和冲突，不只给一条最终红线 |

可选备选方案：将同一结果卡片固定展开在主窗口，使选图只需一次点击，代价是永久占用空间。建议先实现统一弹出卡片，并预留“固定展开”交互；固定后的卡片与弹出的卡片使用同一组件，不维护两个功能重复的视图。本轮不同时扩充所有未验收的图表种类。

## 3. 图内统一上下文

涉及矩阵或频谱的图，其顶部固定显示“实验／数据来源／Run／CPI／时标／是否抽样”。Run 选择显示人类序号1—100，同时在提示中注明内部 `run_id=0—99`。CPI 选择显示“第几窗／总窗数、该 Run 内脉冲范围、中心时刻”，不能只有裸的 `t=...`。原始回波和脉压图没有 CPI，则不显示无意义的 CPI 控件。

默认选中一个完整 Run，Run 内原始回波、脉压和 CPI 结果能相互对应。切换 Run 不跨空档拼接 FFT；改变展示 Run／CPI 不修改配置文件、物理时标或科学估计器。跨 Run 概览作为明确的另一个视图，可以使用“Run × 窗序号”或时间轴留白，禁止把缺测区填成数据，也不把二维显示邻接误称为相干邻接。

本次真实产物上图保留100个 Run 的128个诊断 CPI，每 Run 只有1或2个，不是完整展示每 Run 的5个 CPI。旧文件无法从这128帧恢复其余372帧，也无法恢复原先丢掉的距离列。未来某个未保存 CPI 的图若要重算，必须先明确显示“需要计算该 Run”；保留 Stop 与进度，不能因为查看其他图而静默运行整场反演。

### 3.1 统一计算逻辑，而不只是把按钮放在一起

底层脉压算法目前来自同一份 `radar_signal.matched_filter_chirp`，但调用方分别组织数据读取、补偿、批量大小、裁剪和失败处理：回波查看直接整场调用；特征／反演经 `prepare_chirp_pulse_profiles` 分块或逐CPI调用。这是同一算法被多个业务入口不一致地组织，不能靠把三个按钮并成一个菜单解决。

推荐明确“一个计算服务、多种只读视图”：UI只提交图像类型、来源、Run／CPI与处理定义，不能直接调用FFT或自己决定整场批量。服务统一执行读取、有效性处理、公共补偿、脉压、共同轴与CPI处理，统一负责内存预算、进度、中止、缓存及失败。已有产物可读则直接提供，不再为了换一种画法重做脉压。缓存是否共用由处理定义决定，不是所有名为“脉压”的结果无条件相同。

| 入口 | 操作逻辑 | 是否允许发起计算 |
| --- | --- | --- |
| 原始回波 | 读取选定Run的原始IQ并画图 | 不调用脉压或CPI |
| 脉冲压缩 | 请求选定Run和明确补偿定义的脉压产物，画原生行或对齐坐标 | 缺少相同定义的产物时，只计算需要的Run |
| 实际反演特征 | 读取上次反演保存的特征与参数快照 | 不重做脉压、FFT或周期搜索 |
| 逐脉冲检查 | 请求当前处理定义的逐行特征，优先消费同定义脉压产物或分块提取 | 缺少相同定义的结果时允许明确的后台计算 |
| 距离—多普勒 | 请求选定Run／CPI的复距离像和谱；距离边缘从同一谱归约或用Parseval计算 | 缺少选定谱时由同一服务计算，禁止跨Run |
| 周期搜索图 | 读取上次保存的曲线、候选和决策说明 | 不运行上述计算或重新挑周期 |

至少区分原始基带的未经公共补偿脉压、按反演设置补偿后的脉压、原生行坐标、共同延迟坐标、完整相关和显示裁剪。参考系、补偿、模板、数据来源、坐标或统计支撑不同不能共享一个没有定义的缓存。相同产物可以被多个图消费，绘图入口多少不应决定科学计算实现有多少份。各图按钮实际调用与结果状态是验收项目，不能只给底层函数写测试便宣称所有GUI入口一致。

## 4. 矩阵坐标与显示规范

原始回波和单 Run 脉压图统一采用横轴慢时间／脉冲序号、纵轴质心相对延迟，便于同一 Run 逐层对照；当前原始回波 HTML 横轴快时间、纵轴脉冲是历史显示布局，不代表数组被错误转置。脉压的原生行坐标与公共对齐坐标必须注明，不能把未经对齐的所有行假设为相同质心延迟格。

距离—多普勒图横轴 Hz、纵轴质心相对延迟；只有明确有效转动率和收发几何后，才能选择横向米坐标。上下图如果分别为“逐脉冲距离像”和“单 CPI 距离—多普勒”，应由不同数据直接生成；如果沿用当前 CPI 距离边缘，标题必须写“CPI 距离能量”，不能再写“仅脉压”。推荐把真正逐脉冲脉压留在脉冲压缩入口，距离—多普勒入口默认只展示选定 CPI，CPI 距离边缘作为可打开的辅助小图。

有效区域默认为数据支撑或明确显示规则给出的 ROI，允许一键恢复完整记录范围。注明相对 dB 的参考对象、色标范围、窗函数、距离格间隔、频率格间隔和抽样方式。聚焦显示不改变特征计算门限。真正未观测用留白或无数据标识，不使用与低功率完全相同的黑色混淆；低于动态范围仍可以黑色，但说明不是数值零。零功率图显示“无有效功率”，不伪造归一化参考。

不能在脉压前把200 MHz快时间信号抽稀后继续使用原来的150 MHz模板。匹配滤波及特征始终先在物理采样率上计算；展示缩减放到后面，窄峰不能被简单隔列抽样抹掉。若展示像素不足，比较保峰分箱和有效支撑完整显示，并标注所用方法；不要把“最多500列”硬编码成科学距离分辨率。

## 5. 内存、后台与缓存

所有需要读取大 IQ 或计算的动作进入可中止的后台子进程，界面负责选择和显示。轻量已保存特征、候选和诊断优先复用；不能每次开图都重算。分块只改变执行结构，保持模板、补偿、各入口原有输出范围和标量定义不变：当前回波预览脉压裁回原行宽，科学距离特征使用完整相关范围，二者分别验证。如果预览增加完整相关视图，应明确为新的显示选择及坐标语义，不能叫作原入口的纯等价分块。反演均值／能量宽度不能从显示抽样重新估算。

修复“查看回波”必须覆盖其独立入口，而不是只复用同名匹配滤波函数。若均值谱针对一个 Run，只处理该 Run；全场均值则逐块累计完整行的和与计数，不能拿抽样平均冒充全场平均。NPZ中的压缩数组不具备普通 NPY 的低成本切行能力，选 Run 不能仍先完整物化整场 IQ；应评估 ZIP 内 NPY 数据的有界流式读取。仅跳过前缀可能仍有解压耗时，要显示真实进度，不声称随机访问恒定时间。缓存只核对本机路径、大小和修改时间及真正影响该图的处理参数，不引入文件内容 SHA256。

图像出现“无法做匹配滤波”时，显示具体原因和是否仍有原始图，而不是将失败页面保存为成功的脉压结果。失败、取消、源变化保留旧完整图，但必须明确其旧来源。图文件发布和状态记录一致；图像缓存版本更新要使旧失败图失效。

## 6. CPI 与周期估计的独立验收

1/4步长只代表75%窗口重叠，是当前工程默认，尚无本项目误差／成本实验将它证明为最优。建议在显式步长和CPI长度分开的配置语义下，以相同 IQ、相同时标比较不重叠、50%、75%重叠；报告完整窗口数、信息相关性、计算成本和盲搜误差，不因多了重叠点便宣称多了独立观测。未经对齐，不改默认值。

数值修复依次验证：零多普勒控制、已知正负单频点目标、已知多点距离／多普勒、亚样点偏移、带宽／采样率／窗函数边界、固定几何旋转模型，最后再到当前变化几何真实仿真。分别验证复谱和各标量，不能仅看最终周期是否接近已知5400 s。复采样需要给出幅度和相位误差范围、周期延拓与边界处理；不凭一份点目标就替换所有默认插值。

多普勒质心或 RMS 并不必然有明显半周期调制，例如对称目标的质心可能近似不变。验证必须先建立该形状／散射／视线下的独立物理参考，区分“信号链测量失真”“观测量本身不可辨”与“周期估计失败”。当前额外展宽和候选投票缺陷已存在，尚无充分证据宣称当前 CPI 两项多普勒特征已有效改善周期估计。

共识不能以弱候选的一票压过明显强峰。联合评分和质量门限的具体方案与数据定义单独对齐，必须保留强弱、冲突、别称及采样窗证据；不要硬编码真值、删除不合预期的特征或自动取所有图里最高峰当通用修复。
