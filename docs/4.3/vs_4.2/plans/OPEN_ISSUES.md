## 2. inversion 把重叠保存行当作独立脉冲

生成器在 Run 级唯一 `global_q` 上只计算一次信号和噪声，再按 `row_start_sample` 映射到二维行。`window_overlap` 只表示保存行共享索引。

当前`dataset.load_echo`已读取`row_start_sample`、`window_overlap`、`signal_echo_overlap`，但搜索和特征计算尚未完成按唯一全局ADC样点计权的专门处理。行宽大于PRT时，同一全局样点进入多个保存行，不能默认其统计贡献独立；当前无重叠作业不能验证这一边界。

处理时优先按 `run_id` + `row_start_sample` 去重，或在 `window_overlap` 为真时拒绝或降权。不要改 echo 生成器来切掉真实的物理叠加。

完整推导和当时的代码位置见 `docs/4.2/vs_4.1/plans/KNOWN_DEFECTS.md` 第 2 节。

## 5. 逐组截距会吸收掉周期信号（2026-09-29 定位）

2026-10-11 第一批已修复生产搜索基线：逐脉冲与 CPI 均使用共同截距、保留原始特征时间戳、不按 Run 聚合，并导出路径与失败原因。下文数值保留为旧模型诊断；旧计划的默认聚合、CPI 保留逐组截距及自动阈值均未采用。现有输入与验收见 [共同截距修改记录](../changes/PERIOD_INVERSION_BASELINE.md)。跨特征判读、别称重算、相关性与统计校准仍开放。

**现象**：`configs/paras_for_70m_600s.json`（真周期 600 s）实际反演输出 208.63 s。

**定位**：`docs/4.3/INVERSION_ALGORITHM.md` 的 A5 节。§5.2 式 (8) 的逐组截距在"一次 Run 内的信号变化低于逐脉冲噪声"时会连同周期调制一起被吸收。本次观测 Run 发射段 0.4 s、数据里的周期 300 s，判定量 $\Delta_{\mathrm{in}}/\sigma \approx 0.0025$，因此该模型失效。同一批数据改用不含逐组截距的模型（或先按 Run 聚合）后，真周期升到候选第 1、第 2 位，输出 299.80 s（与半周期 300 s 相差 0.067%）。

**关键结论**：决定可辨识性的第一位因素是 **Run 内信号变化与逐脉冲噪声之比** $\Delta_{\mathrm{in}}(P)/\sigma \approx (A/\sigma)(S_{\mathrm{tx}}/P)$，不是固定的周期百分比。Run 间隔是次要条件：Run 内跨度不足时（$0.4\ \mathrm{s}$）任何间隔都是 0/6 命中；跨度足够后，间隔需给出约 2–4 个采样点/半周期，过疏或过密都会变差（联合扫描见 A5.4）。

**已否定的中间结论（两条）**：A5 首次成文时用无噪声合成实验定出"Run 内相位跨度需占周期 3%–10%"的门槛，该实验不能用（无噪声下检测不失败，量不出边界）。表上约 $0.45\%$ 的差距是 $0.5\ \mathrm{s}$ 步长上的相邻格，不是远处周期也拟合得差不多。期间还一度写成"逐组截距模型在无噪声下真周期不是峰"，那是一个脚本的索引错误造成的，已被正规方程与 QR 两条路线的互校推翻。两处更正均记录在 A5.4。

**历史候选方案的观测约束**：按 Run 聚合后，慢时间序列的可分辨下限约为两倍 Run 间隔（本次 $288.5\ \mathrm{s}$），配置里的 `period_min_s = 200\ \mathrm{s}` 低于该采样限。

**历史计划**：[PERIOD_INVERSION_BASELINE.md](../changes/PERIOD_INVERSION_BASELINE.md#legacy-proposal) 保留当时方案；当前实现以本节首段和最新变更记录为准。

### 2. 优先级最高：现有搜索模型与错误提示

fallback 在 `inversion/src/inversion.py` 传入 `groups=run_id`，搜索为每个组建立自由截距。参数数为 $G+2H$，其中 $G$ 是组数，$H$ 是谐波阶数。当前 $N=G=2000$，默认 $H=1$，参数数 2002；最低残差自由度检查会拒绝搜索。这不是数据恒定，也不能通过增加更多单脉冲 Run 修复，因为样本数与截距数同步增加。

已实际用 20 个不同时间的非恒定余弦样本、20 个独立组重现同类拒绝，报告 20 点、22 参数。上层对每个特征捕获全部 ValueError 后跳过，最终统一报“特征均为常量”，丢失真实原因。

修复建议：逐脉冲标量搜索默认采用共同截距；真实存在的 Run 间增益或偏置用可校准变量、受约束的基线或有明确依据的模型处理，不能给每个单点自由截距。多脉冲短 Run 可选保留原生样本或作 Run 聚合，但聚合后仍不能给每个聚合点自由截距。长 CPI 的基线选择需单独验证，不能无条件照搬。记录每项特征跳过原因，只捕获预期的数据不足或不可估计异常，不吞配置错误。

验收：同一输入比较共同截距、自由组截距与必要的受约束基线；覆盖单脉冲 Run、多脉冲短 Run、长 Run、真实组间增益和带相关残差信号。不把无噪声能恢复当作带噪声失效边界证明，也不以固定已知真周期拟合代替盲搜验收。

### 4. 建议实施顺序

1. 修复 fallback 的组基线策略及失败原因报告，用当前单脉冲 Run 数据首先恢复可搜索性。
2. 调整合理搜索范围，明确输出调制周期与完整自转周期的区别，重新评估别称和候选质量。
3. 在保存的同一数据上做盲搜、采样窗和少量谐波 A/B，建立基准；不以平滑程度验收。
4. 以有分数格点变化的独立输入验证原生标量和 CPI 插值改进；随后扫描采集长度、分位量化与网格收敛。
5. 如需旋转多普勒约束，再实施长 Run/CPI 实验并定义所测带宽，同时加入几何误差、噪声、相关残差与多次实验的不确定度评估。

本次只做只读诊断和计划整理，没有改动周期搜索默认模型、宽度定义、插值算法或配置。现有不确定项必须通过针对性的控制实验判断，不能全部以一个平滑滤波器代替修复。
