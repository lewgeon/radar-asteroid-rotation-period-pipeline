## 1. 优先实施范围

从[EV5独立接手说明](EV5_PRECISION_IMPLEMENTATION_HANDOFF.md)开始，将已用保存数据验证的五特征多谐波正预测增益融合接入生产，作为显式研究选项；保留4.3的`predictive_joint`默认和`legacy_consensus`对照。已知极轴的有限球面响应另设独立选项，不向未知轴输入静默添加先验。输入、频率域、Run分折、复杂度选择、细化规则、金值及拒绝路径均以该交接合同为准，不以更接近真值为验收捷径。

4.3研究原型已降低两份固定EV5数据的无噪声偏差，但70m在部分低SNR档仍有全样本RMSE退化。移植、低SNR错峰诊断、独立场景评价和默认策略变更是不同事项；本计划不设置按已知SNR档位自动切换算法的阈值。方案A沿用原五特征与LOS设置，方案B新增已知轴先验时必须单列。已有结果和失败见[4.3同数据实验](../../../4.3/vs_4.2/experiments/reports/2026-10-16_RECEIVER_SNR_AND_EV5.md#ev5-precision-20261020)，数学依据见[4.3推导](../../../4.3/research/RADAR_PERIOD_ESTIMATION.md#ev5-precision-models-20261020)。

## 3. 工程与重采样后续

| 未完成事项 | 范围与验收 |
| --- | --- |
| ADC规划职责迁移 | 独立执行[迁移计划](ADC_PLANNING_REFACTOR_PLAN.md)，不与精度算法混改；当前生产仍由观测模块规划离散ADC布局 |
| 公共时间伸缩 | 原始基带补偿不能用恒定Fourier平移替代；明确频带、核长和误差预算，以直接连续模型查询值核对 |
| 非均匀慢时间 | 比较受控带限重采样与非均匀Fourier求值，验证缺样与频带边界；符合现有均匀条件时保留直接FFT |
| 零/整数位移性能路径 | 只在实际尚未覆盖的路径实施；同会话、同目标规模A/B并证明数值不变，不从单夹具推广默认策略 |
| 结果缓存及首次导出 | 缺失/损坏单帧的修复与窗口重用独立验收，保留只读查看和配置身份契约，不从看图启动反演 |
| CPI与候选判读 | 既有CPI比较不等于默认1/4步长最优；新增控制需报告相关性、成本与误选，不仅看曲线平滑 |

原生完整脉压统计、共同轴Fourier对齐、GUI A—C、后续只读查看与已完成CPI比较均已落地，历史留在[重采样记录](../../../4.3/vs_4.2/plans/2026-10-10_INTERPOLATION_REPAIR_PLAN.md)和[结果查看记录](../../../4.3/vs_4.2/plans/GUI_RESULT_VIEW_PLAN.md)。其旧方案中的未实施措辞只描述当时，不能覆盖当前契约。

## 4. 交付要求

修改前加载变更验证纪律，固定生产基线与输入身份；测试必须能区分目标分支，使用独立参照而非只比较两个可能同错的实现。先复现交接金值，再做独立场景校准，记录负结果与适用范围。全新上下文对抗性审查为交付门槛。4.4实际实施后将生产说明、实验证据及日志写入本版本，4.3冻结附件不复改。
