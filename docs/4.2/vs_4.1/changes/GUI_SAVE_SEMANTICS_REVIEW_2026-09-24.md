# GUI 保存语义与布局复核（2026-09-24）

本次把顶部配置路径改为只读的当前文件位置。「打开」载入已有 JSON，「保存」始终更新当前 JSON，「另存为」选择新路径并切换当前文件；实验名只决定 `runs/<实验名>/`，保存和另存为都不会据此推导配置文件名。另存为若指向另一个已有文件会报错。跨目录另存为时，已能解析的相对 `echo.model_path` 和 `echo.observation_info_path` 会重新表示为相对新配置目录的路径；无法解析的输入草稿保持原文，供用户继续修改。

审核发现原实现有两处明确的保存风险：配置路径与实验名同时编辑时，保存会忽略实验名且改写它；另存为由 `write_json` 原子替换文件，却未在代码层拒绝覆盖已有配置。新语义消除了两条文件命名路径；新文件先写入同目录临时文件，再以独占的硬链接发布，目标即使在保存过程中由另一进程创建也不会被覆盖。实验名在运行目录生成时统一校验，避免路径分隔符被当作目录结构。另发现「打开」无效 JSON 会让路径显示与实际保存目标不一致；现在读取和规范化成功后才提交新配置，失败时保留原路径及未保存的字段草稿。

布局核验使用 `QT_QPA_PLATFORM=offscreen` 的实际 Qt 事件循环。1280×800 启动时参数区为两列，滚动最大值 715，画布最小高度及卡片内容底边均为 1103；1600×950 时仍为两列，滚动最大值 606，画布最小高度及内容底边均为 1101。测试还执行窄列再恢复宽列、采集路径窗获得焦点后真实鼠标点击只读说明文字，断言两列及滚动边界恢复。离屏截图保存在忽略版本控制的 `tmp/gui_review_2026_09_24/`，因该环境缺少中文字形，仅用于几何复查，不作为字体效果证据。

复现命令：在仓库根目录运行 `conda run -n pytorch python -m pytest tests/test_gui_schema_v4.py -q`，结果为 72 passed；其中有「打开」无效 JSON 后保留未保存草稿、另一进程恰在另存为发布前创建同名文件、以及成功发布后临时文件清理失败的区别性测试。运行 `conda run -n pytorch python -m pytest tests -q`，结果为 145 passed。最初全套测试曾有一项失败：`test_campaign_preview_rejects_individually_infeasible_monostatic_run` 依赖可编辑的 `configs/chirp_mesh_target_test.json` 参数，却硬编码 PRF=2 Hz、脉宽=40 µs 对应的预期。当前试例为 PRF=20 Hz、脉宽=10 ms、路径窗=300 m；现已在测试夹具中显式设置该边界案例所需的 PRF、脉宽和路径窗，不改动试例文件。
