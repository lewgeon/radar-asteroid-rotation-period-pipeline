# CW 与 Chirp 信号的自转周期测量处理方式

本文说明当前项目里连续波（CW）与 chirp 脉冲序列两种波形，在“回波生成 → 反演测量自转周期”这条链路上各自是怎么处理的，为什么 chirp 的效果较差，以及脉冲压缩能否改善。

## 1. 回波是怎么生成的

回波仿真入口在 `echo/src/echo.py` 的 `generate_echo`，核心公式为（对每个接收采样点 n）：

$$
y_n = \sum_i A_{i,n}\, x_{\mathrm{bb}}(t_{\mathrm T,i,n})\, e^{-j2\pi f_c \tau_{i,n}}
$$

其中 $i$ 是三角网格上的面元，$A_{i,n}$ 是面元散射幅度（余弦幂散射 + 散射热点，随自转周期性变化），$x_{\mathrm{bb}}$ 是发射基带波形，$f_c$ 是载频，$\tau_{i,n}$ 是面元双程传播时延（随自转变化，是微多普勒的来源）。

CW 与 chirp 的区别只在 $x_{\mathrm{bb}}$：

| 波形 | $x_{\mathrm{bb}}(t)$ | 含义 |
|---|---|---|
| `continuous_wave` | 常数 1.0 | 纯载波，没有频率调制 |
| `chirp_pulse_train` | LFM 线性调频脉冲串 | 每个脉冲内部频率随时间线性扫过带宽 |

所以 CW 回波就是“面元相干叠加的纯多普勒信号”，chirp 回波则是“每个面元的 chirp 被各自的时延延迟后叠加”。

## 2. 反演当前做了什么（CW 与 chirp 完全相同）

反演入口在 `inversion/src/signal.py` 和 `inversion/src/inversion.py`，`estimate_rotation` 的流程是：

1. （可选）平动多普勒补偿。
2. `stft(iq, ...)` 对复回波做短时傅里叶变换，得到动态谱（时频图）。
3. `spectral_features` 从动态谱提取三条随时间变化的特征曲线：`total_power`（每个时间窗内的总功率 $P(t)=\sum_f |S(t,f)|^2$）、`centroid`（频谱质心 $\bar f(t)=\frac{\sum_f f\,|S(t,f)|^2}{\sum_f |S(t,f)|^2}$）、`rms_bandwidth`（频谱带宽 $\sigma_f(t)=\sqrt{\frac{\sum_f (f-\bar f)^2 |S(t,f)|^2}{\sum_f |S(t,f)|^2}}$）。
4. 对每一条特征曲线，用 Lomb–Scargle 周期图在 `period_min_s`~`period_max_s` 区间内搜索周期，取峰值作为候选。
5. `add_harmonics` 补充半周期/二倍周期候选。

**关键点：这段代码对 CW 和 chirp 一视同仁，没有做任何脉冲压缩 / 匹配滤波**，它只是把 `iq` 直接送进 STFT。

## 3. 为什么这段流程对 CW 有效

CW 回波的瞬时频率就是微多普勒（自转 + 平动），随自转周期性变化。STFT 直接把这条多普勒曲线解出来：`total_power` 反映回波功率包络（自转周期，对称目标下为 P/2），`centroid` 反映多普勒质心随自转的变化，`rms_bandwidth` 反映微多普勒带宽随自转的变化。对这些曲线做周期图，就能找到自转周期（或其混叠）。

## 4. 为什么同一段流程对 chirp 失效

chirp 回波里叠加了两个完全不同的频率结构：**快时间的线性调频**（每个脉冲内部频率扫过带宽，例如 4 Hz / 120 s）和**慢时间的微多普勒**（由自转引起的载波相位变化）。

当前直接用短窗 STFT 处理原始 chirp 回波时，窗长（默认 256 点 = 16 s）远小于脉宽（120 s），一个窗只看到 chirp 频率扫描的一小段；`centroid` 特征主要跟着 chirp 的瞬时频率走而不是跟着微多普勒走；`total_power` 主要反映“当前在脉冲里还是脉冲间隙里”（PRI=180 s 的开关门），旋转调制被这个门信号稀释。所以 chirp 下 `total_power`/`centroid` 都不是干净的旋转特征，周期测量自然变差；再加上对称目标的 P/2 混叠，就出现 1.05 h、3.04 h 这类结果。

## 5. 脉冲压缩能不能改善？

**能，但仅补匹配滤波仍不足以修复当前模型。**脉冲压缩要求先把数据组织为“脉冲慢时间 × 脉内快时间”的二维数组。匹配滤波沿快时间执行，产生每个脉冲的距离像；随后才在同一相干处理区间内沿脉冲慢时间估计多普勒或形成距离—多普勒图。

不能把整个长时观测的一维 IQ 按 PRI 切段后就视为正确的二维数据，因为当前一维轴同时承担了快时间采样和观测历元采样，且发射脉冲时刻与返回接收窗没有通过光行时明确配对。

对扩展目标也不宜只取每个脉压结果的单个峰值复幅度：主散射点可能随姿态切换，单峰序列会引入相位跳变并丢失距离展宽。应保留距离像或选定距离门的复向量，再在 CPI/子孔径内完成慢时间处理。

## 6. 正确的三级时间处理

多次 ISAR 观测用于周期反演时，应区分：

1. **快时间**：单个 Chirp 脉冲内部的高采样率时间轴，用于距离压缩；
2. **相干慢时间**：单次成像/CPI 内的脉冲时间轴，采样率为 PRF，用于多普勒和 ISAR 处理；
3. **观测历元**：多个成像批次或子孔径之间的绝对时间轴，允许时密时疏、跨越一个以上自转周期，用于 Lomb–Scargle 和物理反演。

不同成像批次之间通常不能直接拼接载波相位。应从每个批次或子孔径提取功率、距离展宽、多普勒质心/带宽、图像轮廓或学习型嵌入，并把这些特征连同真实时间戳和观测几何交给长周期反演。

完整架构与迁移步骤见 [Chirp/ISAR 观测与长时自转周期反演的三级时间架构](three_time_axis_architecture.md)。

## 7. 一句话总结

- CW：可在连续相干窗口内直接分析微多普勒，但跨窗口仍须尊重相干边界。
- Chirp：原始数据首先是“脉冲 × 快时间”的二维数据，不能用覆盖整个飞越时段的一维高采样率轴表示。
- ISAR：在有限 CPI/子孔径内形成距离—多普勒或图像产品。
- 周期测量：在多个 CPI/子孔径产品之间建立不规则观测历元序列，再做 Lomb–Scargle 或物理模型反演。
